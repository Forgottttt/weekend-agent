# 十二课学习入口

更新：2026-10-04，来源为本聊天。用户要求一次生成完整项目，再逐课学习，并准备国内AI Agent实习面试。

第一课用户已自述理解；第二课已讲解。用户反馈第三课之后过于简略，本次已将第三至十二课改为详细讲义，补充逐步推演、变量表、错误反例、动手练习及折叠参考答案。没有把代码生成或测试通过当作用户掌握。

每课建议流程：运行→预测变量变化→读对应函数→做一个改动→回答本课四道面试题。

## 这次怎样学

每课分成两遍：第一遍只读到具体输入和变量推演，先预测输出再运行；第二遍做练习，遇到错误先判断发生在哪一层，再展开参考答案。一次不必学完整课，能解释一个例子再向后走。

| 阶段 | 重点 | 能独立完成的检查 |
|---|---|---|
| 3–5课 | 计算、协议、循环 | 手算37元；写配对消息；解释3轮修复 |
| 6–8课 | 检索、校验、记忆 | 拆解BM25；复现预算绕过；画完整历史与上下文 |
| 9–10课 | HTTP与评测 | 复现400；区分状态通过率与计划约束通过率 |
| 11课 | DeepSeek官方接入 | doctor→两轮连通→一条真实规划，逐步验证 |
| 12课 | 解释与修改 | 90秒介绍、两层追问、一条独立改动及测试 |

如果想先接API，可以提前按第11课完成配置，但理解工具调用仍应回到第3–5课。只运行命令不算学完。把自己真正完成的过程写进[学习记录](STUDY_LOG.md)。
