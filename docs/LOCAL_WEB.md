# 本机网页、后端和数据库

更新：2026-10-05。使用现有 Python 标准库后端和 SQLite，无需另装数据库服务。

## 启动

在项目目录执行：

```sh
python3 main.py --doctor
python3 main.py --serve --port 8875
```

打开 http://127.0.0.1:8875/ 。已有本地模型密钥时，新会话默认选择真实模型；也可切换离线演示。模型配置只表示本地配置可读，真实调用仍可能因余额或网络失败。

## 一次网页操作的运行流程

1. 浏览器收集表单，通过 POST /api/plan/stream 发给 Python 后端。
2. PlanningService 校验预算与时间，读取项目根目录 .env，创建 APIProvider。
3. 后端向 DeepSeek 发送模型请求，执行本地工具，独立检查最终方案；SSE 把进度逐条送回网页。
4. SessionStore 在同一 SQLite 事务里更新 sessions，并写入 plan_runs；成功后网页更新历史列表。
5. 浏览器只存会话 ID，后端密钥不会放入页面、localStorage 或数据库。

## 数据库和历史

默认文件：outputs/sessions.sqlite3，已被 Git 忽略。保留这个文件即可保留本地历史；换浏览器也可通过历史列表重新打开。

- sessions：每个会话的完整消息、最新条件、最新结果、乐观锁版本号。
- plan_runs：每次成功生成的条件与结果快照，按会话关联；失败生成不保存结果快照。
- 首次启动自动增加 plan_runs 表，保留原会话。旧版没有保存过的中间结果无法补回。
- 列表最多展示50个会话；每个会话最多展示最近100次生成。
- 点击会话恢复最新结果并可继续修改。点击某次旧结果只查看快照，再生成会创建新会话，避免混用旧表单与当前消息历史。

## 后端接口

|接口|作用|
|---|---|
|GET /api/health|本地配置检查，不调用模型|
|GET /api/sessions|数据库会话摘要列表|
|GET /api/session?id=会话ID|恢复最新结果|
|GET /api/runs?session_id=会话ID|该会话生成记录列表|
|GET /api/run?id=记录编号|读取一次生成快照|
|POST /api/plan/stream|流式生成并保存|
|POST /api/extract|调用模型解析自然语言，填入表单供用户核对|

本版本绑定127.0.0.1，按用户确认用于本机。对外部署、账号和多用户数据隔离尚未实现。

## 杭州主题界面（2026-10-05）

页面顶部使用西湖与雷峰塔的真实照片，保存在web/assets并由本地后端提供。作者、来源与许可列在页脚及素材ATTRIBUTION.md中。背景照片是真实场景，行程继续使用虚构教学地点。

新增拍照打卡、雨天室内、慢逛看展三个快捷偏好，只填入兴趣、雨天和室内外条件，不会直接发起模型请求。生成结果用费用摘要和时间轴展示，参考资料与调用过程按需展开。历史列表默认显示最近六个会话，可展开查看接口返回的全部记录（最多50个）。窄屏页面自动改成单列；减少动画的系统设置会关闭滚动和加载动画。
