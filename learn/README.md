# 从零重写：AI Agent 十步课

这个目录不属于 `src/weekend_agent/` 那份现成代码，而是**重新手写一遍**的学习记录。

两份代码的关系：

- `src/weekend_agent/` 是**答案册**，卡住超过 15 分钟再对照，不要一上来就读。
- `learn/stepNN_*.py` 是本目录，每一步都是**能单独运行**的小脚本，只新增一个概念。

## 三条规则

1. 每一步自己打字，不复制。打错、跑报错、改回来，才是学会的部分。
2. 每一步运行通过、并且能回答该步的"自测"问题，才进入下一步。
3. 不联网。模型调用用自己手写的假模型模拟，协议与真实 API 一致。

## 十步路线

| 步骤 | 文件 | 学到的核心概念 |
| --- | --- | --- |
| 1 | `step01_search.py` | 数据与逻辑分离；函数返回数据而不是文字 |
| 2 | `step02_schema.py` | 工具的 JSON Schema：模型眼里的工具长什么样 |
| 3 | `step03_validate.py` | 参数校验：为什么不能信任模型输出 |
| 4 | `step04_registry.py` | 错误即数据：让模型读到错误并自我修正 |
| 5 | `step05_fake_llm.py` | tool_calls 协议与 tool_call_id 配对（全程最关键） |
| 6 | `step06_loop.py` | Agent 循环：把两轮写死变成自动循环 |
| 7 | `step07_guards.py` | 轮数与调用次数上限：成本与死循环控制 |
| 8 | `step08_verifier.py` | 确定性校验器：用代码压制幻觉 |
| 9 | `step09_trace.py` | 可观测性：把每次调用落盘 |
| 10 | `step10_live.py` | 换成真实模型：循环代码一行不改（需联网，暂缓） |

## 为什么第 10 步可以留到最后

Agent 的工程量在**协议、状态、护栏、校验**这四件事上，HTTP 请求只占 20 行。
第 5 步手写的假模型会返回和 DeepSeek 完全相同的 assistant 消息结构，
所以第 10 步的改动只是换一个对象，第 6 步的循环逻辑保持不变。
这个"换实现不改调用方"的效果，就是面试里能讲的**面向接口编程**。

真实调用最终仍然至少要做一次，成果需要真实调用记录，不能只用假模型。
